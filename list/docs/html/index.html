Skip List C++ Library

Introduction

This documentation describes the SkipList template library, a memory-safe, STL-style skip list.

Basic Example

SkipList<int> sl;
sl.insert(1);
sl.insert(2);
if (sl.find(1)) {
std::cout << "Found!" << std::endl;
}
