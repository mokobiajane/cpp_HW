Detailed Description

template<typename T>
class SkipList< T >

A templated SkipList implementation with unique_ptr ownership and raw pointer forwards.

The skip list stores elements in sorted order and supports insert, erase, find, and iteration.

Template Parameters
TType of elements stored (must be comparable via <).
