Detailed Description

template<typename T>
class SkipList< T >::iterator

Iterator class for SkipList.

This is a forward iterator that allows range-based for loop support. It iterates over the base level (level 0) of the skip list.

Note
Iterators become invalid if elements are inserted or erased during iteration.
for (auto it = sl.begin(); it != sl.end(); ++it) {
std::cout << *it << " ";
}
