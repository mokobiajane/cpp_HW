Detailed Description

template<typename T>
class SkipList< T >::iterator

Forward iterator for SkipList<T>.

Supports range-based for loops and STL-style iteration.

Forward iterator for the SkipList.

This iterator supports standard operations such as dereferencing and increment, and is compatible with range-based for loops.

SkipList<int> sl;
sl.insert(1);

for (SkipList<int>::iterator it = sl.begin(); it != sl.end(); ++it) {
