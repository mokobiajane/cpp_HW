Detailed Description

A templated, STL-style skip list with forward iterator support.

This class provides a skip list data structure offering average-case O(log n) complexity for insert, erase, and find operations. It supports range-based for loops through its forward iterator.

Template Parameters
TThe type of elements stored in the skip list.

Example

#include "skip_list.hpp"
#include <iostream>
int main() {
SkipList<int> sl;
sl.insert(10);
sl.insert(5);
sl.insert(20);
for (int val : sl) {
std::cout << val << " ";
}
std::cout << std::endl;
}
